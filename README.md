# Tiga Display — Landing Page UMKM

Landing page statis untuk **Tiga Display**, usaha box dan display perhiasan dengan konsep **Elegan Modern Premium**.

## Teknologi
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3
- Tanpa database / backend

## Fitur website
- Hero section premium
- Section produk dengan **12 foto produk asli**
- Section galeri foto produk dengan modal preview
- Tentang toko
- Testimoni
- CTA WhatsApp
- Footer kontak
- Google Maps embed dan tombol petunjuk arah

## Cara menjalankan
1. Ekstrak file ZIP.
2. Buka `index.html` langsung di browser, atau jalankan dengan Live Server di VS Code.
3. Koneksi internet diperlukan untuk Bootstrap CDN dan Google Fonts.

## Pengaturan yang bisa diubah
Buka file `js/script.js` untuk mengubah:
- `whatsapp`: nomor WhatsApp toko (sudah diisi: 087720826583)
